
# BTCPOOL

Bitcoin Mining Pool Dashboard

## Website
BTCPOOL is a GitHub Pages frontend for viewing Bitcoin mining pool information.

## Backend
Live mining data will be provided by a secure Supabase Edge Function.

## Security
- PECPool API credentials must remain in Supabase Secrets.
- Never store API secrets or private wallet keys in this repository.
- Live mining statistics should only be displayed when returned by the real API.
